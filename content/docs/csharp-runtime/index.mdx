🚀 **Planned for v1** - The C#/.NET runtime and SDK are planned for the v1 release (target: February 2028), alongside the Azure deployment targets. The C# runtime image provides the .NET runtime, and the core runtime runs your C# handlers as a separate process over the [Celerity IPC protocol](/docs/framework/runtime/handler-ipc-protocol). Documentation will be published as the v1 release approaches.

See the [Celerity versions](/docs/framework/versions) page for the full roadmap.
