🔄 **Planned for v0** - Full SDK documentation is coming soon.

The Celerity Go SDK provides a cloud-agnostic interface for building Celerity applications in Go. Go projects run on an [OS-only runtime](/docs/framework/runtime/lifecycle#os-only-runtimes): the runtime launches your compiled handlers executable and dispatches events to it, rather than hosting the language itself.

For datastore operations, see [Datastore SDK Operations](/docs/framework/applications/datastore-sdk-operations) — the language-agnostic contract every Celerity SDK implements.

For schema management, type generation and schema contracts, see [NoSQL Datastore Schema Management](/docs/framework/applications/nosql-datastore-schema-management).
