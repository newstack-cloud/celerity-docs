The cache package in the Celerity Node.js SDK provides a cache abstraction covering all core Redis data structures and a credentials provider for direct Redis client access.

For the language-agnostic contract these operations implement, see [Cache SDK Operations](/docs/framework/applications/cache-sdk-operations). For the resource type itself, see [`celerity/cache`](/docs/framework/applications/resources/celerity-cache).
