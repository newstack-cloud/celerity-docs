The datastore package in the Celerity Python SDK provides a cloud-agnostic interface for interacting with NoSQL data stores (Amazon DynamoDB, Google Cloud Firestore, Azure Cosmos DB).

For the operations themselves — the full language-agnostic contract, including write preconditions, atomic writes and what each capability costs on each store — see [Datastore SDK Operations](/docs/framework/applications/datastore-sdk-operations). For the resource type, see [`celerity/datastore`](/docs/framework/applications/resources/celerity-datastore).

For schema management, type generation and schema contracts, see [NoSQL Datastore Schema Management](/docs/framework/applications/nosql-datastore-schema-management).
